# D33a-spike-2g-impl-4d — Thin Card Readability and Non-Overlap Layout Guard

This report documents the non-overlap policy for the Authority thin-card PoC.

Policy:

- nodes must not overlap.
- The layout preserves a horizontal minimum gap between card footprints.
- The layout preserves a vertical minimum gap between rows.
- The card footprint is the unit of spacing, not just label text.
