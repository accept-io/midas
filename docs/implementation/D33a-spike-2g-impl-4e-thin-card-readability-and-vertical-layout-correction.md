# D33a-spike-2g-impl-4e — Thin Card Readability and Vertical Layout Correction

This report documents the vertical no-overlap correction for the Authority thin-card PoC.

The policy is that cards must not overlap vertically. row spacing includes card height so adjacent rows reserve room for the complete rendered card, not only the node centreline.

During the design check, sidecar/dotted relationships were considered, but they remained outside this correction tranche.
