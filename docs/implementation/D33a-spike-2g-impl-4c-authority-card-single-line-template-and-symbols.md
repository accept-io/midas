# D33a-spike-2g-impl-4c — Authority Card Single Line Template and Symbols

This report documents the Authority card single-line template and symbol policy for the native Cytoscape PoC.

Design principles:

- icon + colour + legend carry kind recognition.
- The right-side letterbox remains the place for explanatory detail.
- Symbol density is capped at maximum two symbols.
- There is no settings cog on the thin native card.
- There is no second row in the single-line template.
- clicking a node remains the path to inspect the Authority object.
