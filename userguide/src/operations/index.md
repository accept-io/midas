# Operations overview

Operational surfaces in the Explorer help you understand what is happening
between the *projected* state (the Authority Graph) and the *runtime* state
(what agents actually do).

- [Diagnostics](diagnostics.md) — warnings, errors and information records
  attached to the current Authority Graph projection.
- [Drift](drift.md) — divergence between projected authority and runtime
  evidence.

Both surfaces are read-only.
